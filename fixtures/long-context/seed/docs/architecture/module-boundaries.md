# 模块边界
LogParser负责语法和范围校验，不得将非法行变为默认正常请求。
StatusMetrics负责客观状态桶，与告警策略无关。LatencyStats负责确定性的百分位。
AlertEvaluator负责错误率规则，允许业务版本改变。LogAnalyzer通过调用这些模块组装固定8个字段。
解析和数值模块不读磁盘、不输出终端、不访问网络；上层管理日志来源。
兼容性要求：保留公共签名，LogEntry不能改成新的字段布局；调用者按数组下标消费结果。
需求从5xx扩展错误定义时，429排除只能发生在告警错误分子，不能删除日志或改状态桶。
测试时分清原始事故中的观测与规范的期望，旧错误率告警可以被当前实现纠正。
