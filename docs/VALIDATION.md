## v2.3.0 PTC 真实模型验证

默认 PTC 配置结合自动检查点恢复，自主完成相同的64轮访问日志分析项目任务，全部通过独立代码验收。61轮首次通过，3轮经自动回退重试后通过；累计512次 API 请求（375次任务、137次摘要）、7,000,466供应商 Token，包含失败尝试。每轮最多50次模型调用、最多3次尝试；未向模型注入私有验收结果或人工修复代码。验收覆盖代码契约，不自动评价最终回答的每句话。

另有21项 PTC Python 运行时测试通过，覆盖协议、参数校验、原始字符串保留和语法位置反馈。原始请求、会话和完整测试过程保存在本地 `reports/`。

## 工具按需加载版本验证

2026-10-23，工具目录按需加载配置完成 64 轮独立代码验收，62 轮首次通过、2 轮重试后通过，其中第 34 轮由用户发起检查点续跑；运行期间无人工修改代码或注入验收答案。共 711 次 API 请求、10,094,228 Token，包含失败尝试。

对照同轨迹完整历史，计入摘要输入开销后的输入 Token 缩减率为 93.88%；对照同样过滤过期信息的完整历史为 89.76%。工具定义 Token 缩减率为 47.01%，按需加载包含目录和搜索接口开销。以上为离线 tokenizer 对照估算，统计口径与实际 API 用量分别列示。详细口径见[长上下文评测](LONG_CONTEXT_EVALUATION.md)。
